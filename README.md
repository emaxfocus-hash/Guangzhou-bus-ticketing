# Guangzhou Bus Ticketing

This repository contains a starter Android app for a bus ticketing platform serving all regions in Tanzania.

## App branding
- Name: Guangzhou Bus Ticketing
- Slogan: "Your journey. Our priority. Delivered with care."
- Location: Mzumbe University
- Support: +255757817461, +255769281862, +255782264666

## Included in this starter app
- Android native Kotlin project structure
- Home screen with route search UI
- Payment options section
- Support and contact section
- Branding aligned with the requested company identity

## Notes
This is an MVP starter app. You can extend it to add seat selection, route results, booking confirmation, mobile money integration, and a backend API for managing trips and tickets.

## Open in Android Studio
1. Open the project in Android Studio.
2. Let Gradle sync.
3. Run the app on an emulator or physical device.
